# Flux for synthetic image generation

We will be using flux image model to generate sythetic data for your Machine Learning training. We will be finetuning Flux using LoRA. There are two ways you could do so, images only or images+captions. 

# Model Used

Pretrained model from black-forest-labs on huggingface called FLUX.1-dev. This can be changed in the Flux_finetune_LoRA_imageonly/finetune_images.py or Flux_finetune_LoRA_imagewcaption/finetune.py line 49. 

## Images only

Open dir FLux_finetune_LoRA_imageonly. Use this if you want the model to learn more about the body pose, scene, or background. 

## Images + Captions

Open dir FLux_finetune_LoRA_imagewcaptions. Use this if you want to link specific key words to specifc things on the image. This will make flux re-learn the routing of words to images. 

**Notes:**
- Make sure to double check all the images generated by the model to ensure your training data is of quality.
- The captions should be the description of the image as if you are prompting the Image generation model to generate that image.
